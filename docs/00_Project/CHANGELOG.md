## [2.0.0-alpha.1] - 2026-07-31

### Added
- Established `docs/00_Project/` foundation:
  - `PROJECT_VISION.md`: Overall vision, multi-tenant Business OS philosophy, Stripe/Vercel/Linear UX goals.
  - `PROJECT_SCOPE.md`: Strict boundaries focusing on Priority 1 Restaurant OS (POS, KDS, Live Tables, QR, Inventory, AI).
  - `PRODUCT_REQUIREMENTS.md`: PRD detailing functional (FR-01 to FR-07) and non-functional (NFR-01 to NFR-03) requirements.
  - `PROJECT_ROADMAP.md`: Phased milestone plan from documentation bootstrap to production release.
  - `SUCCESS_CRITERIA.md`: SLAs, latency benchmarks (<150ms p95), crash-free targets (>99.95%).
  - `PRODUCT_PRINCIPLES.md`: Core architectural, engineering, SOLID, and UX principles.
  - `PROJECT_GLOSSARY.md`: Technical and restaurant domain terminology dictionary.
  - `CHANGELOG.md`: Project change tracking baseline.
